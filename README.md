# Quiz Game

A simple multiple-choice quiz built in two versions.

## Web version (HTML, CSS, JavaScript)
Open `web/index.html` in any browser. No installation needed.

Features: score tracking, instant feedback with green/red answers, progress counter, restart button.

## Java version (console)
```
cd java
javac QuizGame.java
java QuizGame
```

Features: arrays for questions and options, loops, if/else, input validation.

## How to add questions
- Web: add a new object to the `questions` array in `web/script.js`.
- Java: add an entry to `questions`, `options`, and `correctAnswers` in `QuizGame.java`.
